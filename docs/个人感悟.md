# 个人感悟
我最后选择做金属表面缺陷分类，主要考虑了两个方面：一是这个问题有比较明确的实际应用场景，二是公开数据集比较容易获得。这样可以把有限的时间放在理解模型和分析实验结果上，而不是花大量时间收集图片。
刚开始接触卷积时，我只知道它是神经网络中的一层，并不清楚它到底在图片上做了什么。结合这次实验后，我慢慢理解到，图片本质上是一组数字，卷积会在局部区域内进行计算，把原始像素转换成特征图。不同的卷积参数会对边缘、纹理或其他局部结构产生不同反应，后面的网络再利用这些信息判断缺陷类别。
训练过程也让我改变了对“模型学习”的理解。模型不会直接记住“某张图片对应某个答案”，而是在不断预测、计算损失、更新参数的过程中，逐步找到区分不同缺陷的规律。训练准确率从 68.54% 提高到 95.56%，说明模型在训练数据上越来越熟悉，但这并不能说明它对所有新图片都同样可靠。
训练集和验证集的作用也不一样。训练集用来调整模型参数，验证集则用来观察模型在没有参与参数更新的数据上的表现。因此，最后一轮不一定是最好的结果，这次实验中第 13 轮的验证准确率最高，所以保存了那一轮的模型。
混淆矩阵让我看到，只看一个总准确率是不够的。本次验证集的总体准确率是 91.94%，但夹杂类的召回率只有 71.67%，其中 17 张被预测成了麻点。如果只看总分，很容易忽略这个类别的问题。
我实际查看了几张错误图片：有的夹杂呈零散小点，有的是细长条，还有的是成片区域；麻点图片也有稀疏和密集的情况。两张条状夹杂图片看起来主要是位置不同，但模型的判断并不一样。现在我还不能确定具体原因，所以把它记录为待验证的问题，而不是直接下结论。
这次项目让我感受到，机器学习不只是写出一个能运行的模型。数据是否可靠、训练过程是否记录完整、不同类别表现是否均衡，以及错误结果能否解释，同样是项目的一部分。一个较高的指标只能说明模型在当前数据和设置下取得了不错的结果，不能直接代表它已经适合所有真实工业场景。
