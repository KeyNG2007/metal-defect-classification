# 个人感悟

我选择金属表面缺陷分类，是因为它具有实际应用价值，而且有公开数据集，能够把时间集中在模型实现和分析上。

学习过程中，卷积让我印象最深。我开始不理解特征图的含义，后来知道了图片可以表示为数字数组，卷积对局部像素进行计算，得到特征图，为后续分类提供信息。

通过混淆矩阵，我认识到不能只看总准确率。虽然本次验证准确率达到 91.94%，但夹杂类召回率只有 71.67%，有 17 张被误判为麻点，因此还需要分析各类别的表现和实际错误图片。

我观察到夹杂图片有零散小点、细长条和成片等不同外观，麻点图片也有稀疏和密集的情况。对比两张条状夹杂图片时，肉眼看到的明显区别主要是位置，但模型的判断不同。目前我还不能确定误判原因，因此没有把猜想当成结论。

本项目使用了 AI 辅助解释概念、提供代码示例、排查报错和整理文档。实验数据来自实际运行，图片观察来自自己的检查。我还需要继续理解代码中的细节，不能把程序运行成功等同于完全掌握。
